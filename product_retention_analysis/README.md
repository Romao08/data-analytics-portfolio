# Product Analytics & User Retention Analysis

## Project Overview

This project was completed as part of a client evaluation and focuses on investigating user engagement and retention in a digital product.

The analysis explores user behavior across the first four weeks, with particular attention to changes in meaningful exercise engagement between weeks 2 and 4.

## Business Objective

Understand user retention patterns, identify potential engagement barriers, and provide actionable recommendations to support product improvements.

## Tools & Technologies

- SQL — cohort analysis, retention metrics, user segmentation, and behavioral analysis
- Python (Pandas, NumPy) — data cleaning, validation, and exploratory analysis
- Data Quality Checks — missing values, inconsistencies, and validation of key metrics

## Methodology

1. Cleaned and validated the source datasets using Python.
2. Defined meaningful exercise engagement using the product's weekly adherence metrics.
3. Analyzed user retention and engagement across weekly cohorts using SQL.
4. Investigated behavioral patterns and potential drivers of declining engagement.
5. Summarized findings and recommendations in a presentation.

## Key Deliverables

- Python script for data cleaning and validation
- SQL queries supporting the retention and engagement analysis
- Analytical presentation with findings and recommendations

## Project Files

- `01_data_cleaning_and_validation.py` — Python data cleaning and validation
- `02_analysis_queries.sql` — SQL analysis and retention calculations
- `Bloom_Product_Data_Challenge.pdf` — Presentation of findings and recommendations
